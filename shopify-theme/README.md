# Tema Shopify da volta.

Este diretório contém o tema `volta. | Studio`, publicado na loja `6rkgre-je.myshopify.com`. É um tema Shopify independente da aplicação Next.js deste repositório.

## Desenvolvimento

Na raiz deste diretório, use o Shopify CLI autenticado na loja:

```sh
shopify theme check
shopify theme dev --store 6rkgre-je.myshopify.com
```

Para enviar alterações, confira o ID e o estado do tema com `shopify theme list --store 6rkgre-je.myshopify.com`. Faça a revisão em uma prévia antes de publicar. O tema inclui imagens recortadas de referência; as fotos e especificações de cada unidade devem ser cadastradas como produtos na Shopify.
